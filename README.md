# Calculadora de Tarifas - Club de Ajedrez

Aplicación web para calcular costos de clases de ajedrez según el número de alumnos.

## 🚀 Características

- Cálculo automático de tarifas (3 tramos).
- Generación de PDF profesional con cotización.
- Diseño responsivo y elegante.
- Soporte para modo oscuro.

## 📦 Instalación

```bash
npm install
npm run dev
